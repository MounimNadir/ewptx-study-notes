# eWPTX Study Journal

My personal study journal for the **eWPTX** (Web Application Penetration Tester eXtreme)
certification by INE Security. I add notes, lab write-ups and small tools as I progress.

> 🚧 **Work in progress.** This repository grows with my preparation; sections marked ☐ are planned.

## Repository structure

| Folder | Content | Status |
|---|---|---|
| `00_Admin/` | Study plan and exam logistics | ☐ Planned |
| `01_Notes/` | Topic notes written in my own words | 🟡 In progress |
| `02_Labs/` | Lab write-ups: goal, approach, findings, remediation | ☐ Planned |
| `03_Tools/` | Small helper scripts written during the labs | ☐ Planned |
